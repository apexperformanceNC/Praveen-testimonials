# Praveen — Testimonial Website

This folder contains the complete one-page website for Praveen.

## What is inside?

- `index.html` — the webpage
- `style.css` — the design
- `images/` — the testimonial photos

## How to put it on GitHub Pages

You do NOT need to understand or edit the code.

1. Create a new GitHub repository named `praveen-testimonials`.
2. Upload `index.html`, `style.css`, and the entire `images` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder.
6. Click **Save**.
7. GitHub will give you a public website address.

If you want to change or add testimonials later, it is safest to send the new testimonial and photo back to ChatGPT and have the page updated.
